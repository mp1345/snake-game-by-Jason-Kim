## 贪吃蛇游戏

纯 HTML + CSS + JavaScript 单文件实现，零依赖，无需安装任何东西。

### 怎么玩

直接双击 `index.html` 用浏览器打开即可。

- 方向键 或 WASD：控制蛇移动
- 空格：暂停 / 继续
- 吃到红色食物 +10 分，撞墙或撞到自己游戏结束
- 最高分自动保存在浏览器本地（localStorage）
